## 2. UX changes

- `lde run` now emits compact public progress on `stderr` and a structured
  English summary on `stdout`.
- The summary presents system identity, existing collection areas, evidence
  counts, health status, findings/recommendation/limitation counts, and the
  exact absolute report path.
- The default path no longer prints the Markdown report.
- `--print-report` prints the generated Markdown exactly once after the
  summary.
- `--verbose` enables the existing detailed progress path with public English
  labels (`Collecting diagnostics`, `Analyzing evidence`, `Generating report`)
  and still does not print the report.
- Public CLI help, progress, errors, and summary framing are English-only.
  The existing Markdown report remains unchanged and is intentionally not
  translated in this presentation-only task.
- Display status is deterministic and uses existing finding severity only:
  `P0/P1 -> PROBLEMS`, `P2/P3 -> ATTENTION`, and no actionable severity
  (`Info` or no findings) -> `HEALTHY`.
- ANSI is limited to the status word, enabled only when the output stream is
  a TTY, and disabled whenever `NO_COLOR` is present. Separators are capped
  by detected terminal width with a safe fallback.
- Product version is `0.1.3`; `REPORT_COMPATIBILITY_VERSION` remains `2.1.0`.
