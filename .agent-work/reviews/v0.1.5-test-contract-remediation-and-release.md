## Exact remediation

Only `test_syscheck.py` was changed to remediate the failed test contract:

- `_extract_single_backticked_command()` obtains the single command from the
  actual recommendation or verification field.
- `_run_exact_recommendation_command()` executes that unchanged string through
  `bash -c`, while a temporary `journalctl` stub supplies deterministic stdin.
- ACPI executes both emitted commands against the real supported positive form
  containing `ACPI BIOS Error` and `AE_NOT_FOUND`, and rejects
  `ACPI: Interpreter enabled` with return code 1 and empty stderr.
- RCU executes both emitted commands against a positive stall line, and
  rejects a benign RCU boot message with return code 1 and empty stderr.
- Tests assert the subprocess receives exactly `["bash", "-c", command]`, the
  expected stdout, and no regex/parser warning on stderr.
- No live journal dependency was added to unit tests.
